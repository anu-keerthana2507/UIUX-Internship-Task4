# Student Attendance Management System

## Project Overview

The Student Attendance Management System is a simple web-based application developed as part of my UI/UX Internship Testing and Quality Assurance task.

The system allows students to log in, view their attendance dashboard, mark attendance, view attendance records, and check their attendance percentage.

## Features

- Student Login
- Student Dashboard
- Mark Attendance
- View Attendance History
- Student Profile
- Attendance Percentage
- Error Handling
- Navigation Testing

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub

## Testing Performed

The application was tested for:

- Valid login
- Invalid login
- Empty input fields
- Attendance submission
- Attendance records
- Profile information
- Navigation between pages
- Error handling

## Test Result

All major functional test cases were successfully tested and passed.
